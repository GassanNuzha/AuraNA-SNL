# Aura North America — Website

Everything inside the `site/` folder is the website. Upload the **contents** of `site/`
(not the folder itself) to Hostinger and the site is live.

## Deploy to Hostinger (≈5 minutes)

1. Log in at **hpanel.hostinger.com**.
2. Make sure a **hosting plan** is attached to the domain (a domain alone is not hosting —
   if there's no plan yet, any shared "Web Hosting" plan works).
3. Open **Websites → Manage** for auranorthamerica.com → **File Manager**.
4. Go into the **`public_html`** folder. Delete any default/placeholder files in it.
5. Upload **`aura-site.zip`** (in this folder) into `public_html`, right-click it → **Extract**,
   then delete the zip.
6. Visit the domain — the site is live. (If you see an old page, hard-refresh: Ctrl+F5.)

Alternative: upload with any FTP client (FileZilla) using the FTP credentials from
hPanel → Files → FTP Accounts. Upload everything in `site/` into `public_html`.

## The quote form

`contact.html` posts to `send-quote.php`, which emails the request (with the attached
drawing) to `$TO`. PHP `mail()` works on Hostinger out of the box, **but**:

- Set `$FROM` in `send-quote.php` to a mailbox that exists on the hosting account
  (e.g. create `website@auranorthamerica.com` in hPanel → Emails) so messages don't land in spam.
- Test it after deploying: submit the form and check the inbox (and spam folder).
- The form does not work when previewing locally (needs PHP on the server) — that's expected.

## The customer portal (phase 2)

`portal.html` is the front door only. The sign-in form intentionally does nothing yet except
show a message — a real portal (customer accounts, live inventory, documents) needs a backend
with a database and secure authentication. That's a separate project; the public site doesn't
depend on it.

## Editing content later

- All text lives in plain HTML files in `site/` — open any page, edit the words, re-upload that file.
- Colors/fonts are defined once at the top of `site/css/style.css` (`:root` variables).
- The nav menu and footer are repeated in every HTML file — when changing a menu item,
  change it in all files (search & replace across the folder).

## Local preview

Double-clicking `index.html` works for a quick look, or run a mini web server:

```bash
python -m http.server 8090 --directory site
```

then open http://localhost:8090
